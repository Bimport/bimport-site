## 数字の意味

- **訪問数**：セッション数。ページ表示回数・ユーザー数とは別の指標。
- **査定依頼数**：`generate_lead` のキーイベント数。サーバーが受付成功を返したときのみ送る。実車査定や買取成立の件数ではない。
- **査定獲得率**：`generate_lead` があったセッション数 ÷ セッション数（セッションのキーイベント率）。1回の訪問で複数回送信しても率の分子は1セッション。
- **入口ページ別**：ランディングページごとのセッション・獲得率。そのページから訪れ、別ページのフォームで送信した場合も入口ページの成果。
- **送信ページ別**：ページパスとキーイベント数で、実際に送信されたフォームの場所を確認。メールの「ページ」と対応する。
- `home` はトップ、`vehicle_lp` は車種LP、`other` はプライバシーページ等。`vehicle_slug` は静的ページの識別子で、フォームで入力した車種名ではない。

過去の未計測期間は復元できない。Google検索のクリックと、全流入のフォーム依頼を直接割らない。通常レポートには処理待ちがあるため、導入直後はリアルタイムで受信を確認する。広告ブロック・解析停止などにより、メール件数とGA4は完全一致しない。

## イベント

| イベント | 発火条件 | キーイベント |
|---|---|---|
| page_view | 公開ページの初回表示。GA4 configで1回 | いいえ |
| estimate_start | フォームの最初の入力・選択。ページ内で1回 | いいえ |
| estimate_step | 入力チェックを通って次のステップへ。各ステップ1回 | いいえ |
| generate_lead | 本番送信先から `ok:true`。ページ内で1回 | **はい** |
| estimate_error | 送信失敗。入力内容やエラー詳細は送らない | いいえ |
| cta_click | 査定・LINE・電話ボタンのクリック | いいえ |
| estimate_test_complete | デバッグ閲覧で成功した場合の専用イベント | いいえ |

LINE・電話のクリックは依頼完了ではない。キーイベントにしない。`generate_lead` はイベントごと1回、金額のデフォルト値なし。`estimate_submit` を追加キーイベントとして二重計測しない。

## 個人情報と除外

- 氏名・電話番号・メール・自由入力・フォーム値はGA4に送らない。許可したイベント名とパラメータだけを送る。
- `page_location` は静的canonical。クエリとハッシュを除く。外部参照元はドメインのみ。UTMを使う広告・施策の詳細計測を追加する際は別途設計する。
- localhost・別ドメイン・下書きではGoogleタグをロードしない。
- GASが `test:true` を返す場合、送信先未設定のデモ、ハニーポット入力あり、失敗応答は査定獲得に数えない。
- 社内確認で使う各端末・各ブラウザで次を1回開く：<https://bimport.jp/privacy.html?analytics=off#analytics>
- 以後は同じブラウザのトップ・全LPを除外。保存データ削除・別ブラウザでは再設定。Google Search Consoleのクリックには影響しない。
- 再開：<https://bimport.jp/privacy.html?analytics=on#analytics>
- 開発確認：`?analytics_debug=1` を付けるとDebugView向けイベントになる。実依頼のテスト送信を無断で行わない。GA4のデベロッパートラフィック除外設定も確認する。

- 共通タグ：`src/_includes/ga4.njk` → `src/assets/js/analytics.js`
- 両フォーム：成功応答を保持し、受付成功だけ `generate_lead` を送る。
