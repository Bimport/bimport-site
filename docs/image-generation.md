# 車種LPの画像の作り方（FV画像・実績写真）

車種LPで使う画像は、ChatGPT（Plus）の画像生成で作っています。
生成した画像は、準備表データ（`~/Desktop/Bimport Google投稿/準備表データ/画像/`）に保存し、LPには最適化して入れます（→ [vehicle-lp-workflow.md](vehicle-lp-workflow.md)「4. 写真のルール」）。

## FV画像（車種ごとに1枚）

ルール（ユーザー指定）：
- **車の正面が画面の左側を向く**（実績写真は正面が右向きなので、FVは逆にする）。
- ボディカラーは**その車種で人気があり見栄えのいい色**で、**実績の車両とは違う色**にする。
- 背景は**その車の雰囲気に合う景色**にし、**全車種で背景が重ならない**ようにする（同じ街・似た構図も避ける。例：海沿いの崖道、北欧の港町、アジアの夜景、ぶどう畑、雪景色、紅葉の山道などは1車種ずつ）。
- **背景にも看板・ネオンサインなどの文字を入れない**。車のエンブレムは可。

指示文のひな形（1つのチャットで続けて生成する。車種ごとに新しいチャットを作らない）：

```
次の条件で、広告用の写真のようにリアルな画像を1枚生成してください。
・車種：{車種と型式}
・ボディカラー：{色}
・向き：車の正面が画面の左側を向く、左斜め前から見たアングル（フロントとボディ側面が見える）
・背景：{背景}。その車の雰囲気に合った、写真として自然な景色
・車体全体（前後のタイヤとルーフ）が画面に収まり、上下左右に少し余白を残す
・ナンバープレートは無地で文字なし。画像内に文字・ロゴ・透かしは入れない（背景の看板・ネオンサイン・建物の文字も入れない）
・横長（3:2）
```

できた画像は、向き・文字の有無・ほかの車種との背景の重なりを確認し、だめなものは背景を変えて作り直す。

## 実績未掲載版の画像（2026-11-03 ユーザー指定）

実際の買取実績がまだ掲載できないLPは、1車種につき車種イメージを2枚生成する。

- FV用：その車種に合う屋外の景色。車の正面を左向きにし、車体全体を収める。
- LINE査定用：FVとは別の場所・別のボディカラー・別アングルで生成する。実在する世代・ボディ仕様の範囲で形の違いを付けてもよい。白壁ショールーム写真にはしない。
- 生成画像は実績欄に使用しない。「AI生成の車種イメージ」と表示し、実際に買い取った車と誤認させない。
- 後日実績ができたら、実績カードには実車の写真を白壁に加工したものを使い、LINE写真も実車写真に変更する。FVの車種イメージは維持できる。
- 2026-11-03はアベンジャー1車種のみ先に制作し、ユーザー確認を受けてから残り9車種へ展開する。

## 実績写真（買い取った車両ごと）

以下の白壁加工ルールは、実際に買い取った車両の写真に適用する。

- **実車の正面写真**（`~/Desktop/Bimport Google投稿/正面写真/`）をChatGPTに添付し、**背景だけ**ロゴ・文字・看板のない白壁のショールームに差し替える。**車そのもの（色・ホイール・形・キズや損傷）は変えない**。一から生成した車の写真は実績に使わない。
- 背景の見本として、既存の実績写真（ショールーム・ロゴなしの白壁・光沢のある床・左奥に観葉植物とガラス窓）を最初に一緒に添付する。

指示文のひな形：

```
今添付した写真の車（実際に買い取った{色}の{車種}）を、ロゴなしの白壁のショールーム（壁にロゴ・文字・看板・装飾なし、光沢のある床、天井のダウンライト、左奥に観葉植物とガラス窓）の背景に置き換えた写真を1枚作ってください。
・車そのもの（ボディカラー、ホイール、ボディの形、ライト、グリル、バンパー、キズや凹みなどの状態）は写真のまま変えない
・背景の壁は無地の白。Bimportを含むロゴ・文字・看板・透かしは入れない（車体の純正エンブレムはそのまま）
・向きとアングルも写真と同じ（車の正面が画面の右側）
・車内の人や物は消す
・ナンバープレートは無地の白で文字なし
・床に車の自然な映り込みと影を入れる
・横長（3:2）、車体全体が収まるように
```

- LPでは 1200×900（4:3）に中央で切り抜いて `src/assets/images/cases/` に置く。
- 既存写真の背景にロゴがある場合も、車体を変えずロゴとその影だけを除去して自然な白壁にする。修正前の画像は保存しておく。
- **LINE写真査定用の写真**もロゴなしの白壁に統一し、その車種の実績写真から人気の仕様・色の1枚を選ぶ（準備表に別の写真が入っていればそちらを優先）。

## 注意

- 2026-10-16以降はロゴなしの白壁が標準。既存の下書きブランチを取り込む際は、修正済みの実績・LINE画像を優先し、古いロゴ付き画像に戻さない。

- ChatGPT Plus の画像生成には上限がある（上限に達すると約12時間使えない）。上限に近づいたら止める。
- ChatGPT が「どちらの画像が好みですか？」と2枚出すことがある。向きと背景の条件に合う方を選ぶ。

FV画像の表示は既存LP同様に上下の透過グラデーションで背景へなじませる。実績未掲載欄には案内文のみを表示し、掲載前の相談を促す一文と専用ボタンは置かない（2026-11-03 ユーザー指定）。
